# Частые ошибки и где их искать

**Стили не применились**
<span class="muted">файл не сохранён · неверный путь в href · нет rel="stylesheet"</span>

**Одно свойство не работает**
<span class="muted">пробел в значении · нет двоеточия или точки с запятой · правило перебито</span>

**Блок ведёт себя не так**
<span class="muted">content-box вместо border-box · жёсткая height · схлопывание margin</span>

Блок не центрируется — не задана ширина. Текст не по центру — положение блока задаёт `margin`, текста — `text-align`.
